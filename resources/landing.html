A browser-based, Unix-flavored virtual operating system.

root@fractal:~# uname -a

root@fractal:~# cat features.txt
- Zero server backend required
- Pure Python kernel via Pyodide
- Persistent Virtual File System (VFS)
- Dynamic Package Manager (pkg)
- Built-in Samwise AI Agent

Features

🌐 100% Client-Side

Runs entirely in your browser using WebAssembly. Host it statically on Neocities, GitHub Pages, or anywhere else. No backend required.

🐍 Python Kernel

FractalOS uses a true Python execution environment. Commands are pure Python scripts. Run your own scripts directly inside the OS.

🧠 AI Agent Built-In

Samwise is an intelligent agent living inside the OS. Hook up your Gemini or Ollama API key to chat, dredge memory, and automate tasks.

📦 Package Manager

Extend the OS on the fly. Use the pkg command to download and install custom commands directly from the community registry.

💾 Persistent VFS

Your files, aliases, history, and users are saved securely in your browser's IndexedDB. Export and import snapshots anytime.

💻 Portable Mode

Wrap it in Neutralinojs for a native desktop experience with true host filesystem access and WebRTC signaling capabilities.

Getting Started

FractalOS requires no installation. Just click the Boot button above. To learn the ropes, type help or run the interactive adventure game!
