WHAT.TXT 01 / PLAIN ENGLISH [ □ ]

01 What it is

A small computer that happens to be a web page.

FractalOS boots a real Python kernel inside WebAssembly, mounts a virtual file system, and hands you a Unix-shaped shell. The terminal is not a simulation of a terminal. The Python is not a simulation of Python. The browser is the hardware.

That means you can open it on a machine where you cannot install anything, in a tab, and still have files, users, permissions, pipes, scripts and a package manager. Close the tab and the machine stops. Open it again and your work is still there, because the browser remembers it.

The AI is not bolted on. Samwise lives in the shell, sees the file system, proposes a plan and runs it through the kernel. You can watch, approve or stop it. If you prefer to type, it stays out of the way.

FIRST FIVE MINUTES

  1. 01
    Open it. Make a local account. The username and password never leave this browser.
  2. 02
    Type help. Or ask Samwise for a folder, a script or a summary.
  3. 03
    Run some Python. python -c "print('hello')" is a whole program.
  4. 04
    Take it with you. Download a file or export the VFS before you clear site data.

WHAT IT ISN'T

Not a Linux distro. It runs inside the browser; it is not booting your hardware.
Not a cloud service. There is no FractalOS account and no file server in the middle.
Not a hardened sandbox. The kernel is powerful on purpose. Treat it like a shell.
Not a daily driver. It is a playground, an appliance, a second computer.

03 Capabilities

What is actually in there.

Not a feature list for a pitch deck. These are the parts you can use on the first day.

01

Unix, without the install

150+ COMMANDS

ls, grep, awk, sed, find, pipes, redirects, background jobs, sudo, users and groups. The vocabulary is familiar; the machine is a tab. Story snapshots and /var/log/audit.log are part of the furniture.

$ ls /
etc  home  var
$ df -h
FractalOSVFS  640M  76B  640M  0% /
02

Real Python, not a demo

CPYTHON 3.14

Run a script, a one-liner or a pipeline. open() reads and writes the virtual file system with its permissions. The kernel's own CPython does the work, not a JavaScript approximation.

$ python -c "print(2**10)"
1024
$ python -c "import sys; print(sys.version[:6])"
3.14.2
03

An agent with brakes

SAMWISE

Samwise sees the files, plans in commands and executes through the kernel. Every step has a voltage. Destructive steps ask first; --force is explicit; --dry-run runs nothing at all.

$ samwise --dry-run "tidy ~/notes"
# prints the plan and voltage.
# touches nothing. that is the point.
04

A mesh, not a cloud

P2P / OPT-IN

Two tabs, two laptops or two Pi's can find each other and share a shell, copy files, or hand a task to a peer's agent. The signaling server introduces them; the data goes direct.

$ peers
$ attach oos-7f2a
$ mesh-cp notes.md oos-7f2a:/home/Guest/
$ mesh-agent oos-7f2a "summarize notes.md"
05

An OS, not a prompt

WINDOWS / PANES

Split the terminal, dock the process monitor, open the editor, the ASCII paint studio, the journal, BASIC, the text adventure, the document analyst or the chat. Windows, panes, clipboard and sound are part of the shell.

$ split-h
$ top --dock
$ edit notes.md
$ paint
$ basic
$ adventure
06

A package manager with a spine

SHA-256 / AUDIT

Install from a local repo or the community standard library. Packages carry hashes, dependencies and permission scopes. pkg audit reads the AST before you trust one; execution re-checks the hash.

$ pkg search cowsay
cowsay (v1.0.0 by FractalOS Community)
$ pkg verify cowsay
$ pkg audit cowsay
07

Hardware, when you ask

GPIO / PI

On a Raspberry Pi or a provisioned x86 box, the same shell can read pins, watch a button, stream a sensor and trigger an LED. The appliance build boots straight into the OS.

$ gpio read 17
0
$ gpio monitor 17 --trigger rising
$ gpio write 17 1
AUDIENCE.TXT 04 / HONEST FIT [ □ ]

04 Who it is for

Built for the curious. Not for everything.

FractalOS is a sharp tool with a narrow shape. It is better to know that before you boot it.

THIS IS FOR YOU IF...

  • You have ever wanted a Linux-shaped playground that starts with a URL.
  • You keep a home lab, an old laptop or a Raspberry Pi with nothing to do.
  • You want a local model to touch real files, not just talk about them.
  • You are teaching someone what a shell is and do not want a setup ritual first.
  • You like small, weird, self-contained software that does not phone home.

DON'T USE IT FOR...

  • A production server, or the only copy of something you cannot lose.
  • A hardened security boundary. The kernel is powerful by design.
  • A replacement for Linux, Windows or macOS on your main machine.
  • An AI that works with zero setup. You bring a model or an API key.
  • A public-facing shell on an untrusted network. There is no auth on the mesh.

It is for the person who reads man pages for fun, and for the person who would rather ask a question than read one.

05 Run it

Three ways to boot.

The browser build is the fastest. The desktop build is the double-click one. The appliance build is the one that stays on.

FRACTAL SYSTEMS / QUICK START CARD FORM 1.0 / KEEP NEAR TERMINAL

A / BROWSER

Fastest.

Serve the folder over HTTP and open the page. There is no build step and no package install.

git clone https://github.com/aedmark/FractalOS.git
cd FractalOS/resources
python3 -m http.server 8000

Open http://localhost:8000. It needs HTTP, not file://, because the kernel fetches its Python files.

B / DESKTOP

Offline-native.

Run it as a standalone Neutralinojs window with a real local data/ folder.

# put the Neutralinojs binary in the repo root
./neutralino-linux_x64
# or neutralino-mac_x64 / neutralino-win_x64.exe

The data lives beside the binary. No browser chrome, no tab to lose.

C / MESH + APPLIANCE

Always on.

Turn an old x86_64 box into a signal server, a full-time peer or a kiosk.

sudo ./extras/provision_x64.sh --role signal
sudo ./extras/provision_x64.sh --role node
sudo ./extras/provision_x64.sh --role kiosk

A node needs a screen once for first-run setup. The web server and relay have no auth: keep them on a trusted LAN. The Pi script is in extras/provision_appliance.sh.

WHAT YOU NEED

A modern browser (Firefox or Chromium), a little patience on first boot, and no account. For Samwise: a local Ollama model or a Gemini key. For the mesh: a trusted network.

06 Inside

Two runtimes, one contract.

The trick is not that it runs Python in a browser. The trick is that Python and the browser agree on a small, strict border.

STAGE / JAVASCRIPT

The visible machine

terminal · windows · apps
audio · clipboard · mesh UI

syscall() < JSON > effects

KERNEL / PYTHON

The source of truth

VFS · users · commands
executor · audit · AI

INDEXEDDB the file system persists here JSON

The effect contract

Python never touches the DOM. When it needs the browser to play a sound, open a window, split a pane or copy to the host clipboard, it returns a structured effect. JavaScript performs it.

{
  "effect": "play_sound",
  "notes": ["C4", "E4", "G4"],
  "duration": "4n"
}

QUESTIONS.TXT 07 / THE HONEST ANSWERS [ □ ]

07 FAQ

Questions, answered.

Is this a real operating system?

It is a virtual one. It has a kernel, a shell, a file system, users and permissions. It is not a Linux distribution and it does not boot your hardware; it runs inside the browser or inside a desktop wrapper.

Do I need to know Linux?

No. help lists every command, and Samwise accepts plain English. If you already know Unix, the shape will feel familiar; if you don't, you can still make a folder, run Python and keep notes.

Do I need an API key?

Not for the shell, files, Python, apps or mesh. Samwise needs a local Ollama model or a Gemini key; Chidi uses the same provider. The key is stored in /etc/ai.conf inside the OS.

Where do my files go?

Into IndexedDB in this browser. Nothing is uploaded by default. Export a snapshot or download files before you clear site data. Mesh transfers and cloud AI prompts are the exceptions you choose.

Does it work offline?

Yes, once the files are served, because everything is vendored: no CDN and no backend. A local Ollama model keeps Samwise offline; Gemini needs a connection.

Can it break my computer?

The browser build is sandboxed by the browser, and file operations stay in the virtual file system. A provisioned appliance or GPIO actions can touch hardware, so treat those with the same care as any shell.

Is it safe to expose to the internet?

No. The mesh and its signaling relay have no authentication. Run it on a trusted LAN, or put an authenticated proxy in front. Do not put secrets in a public instance.

Why not just use ChatGPT?

A chat window gives you text. FractalOS gives the model a file system, a shell, apps and a mesh, with a voltage brake and a dry-run. It is a place to do work, not just talk about it.

Why not just use Linux?

You can open this in a tab on a machine where you cannot install Linux. It is a playground and an appliance, not a replacement for your daily driver.

What does it cost?

Nothing. FractalOS is MIT licensed. You pay only for a cloud model if you choose Gemini, and nothing if you run Ollama locally.
